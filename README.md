Dominique Design — Landing Page de Agendamento

Landing page responsiva para o Dominique Design, desenvolvida para apresentar os serviços de beleza e permitir que clientes realizem um agendamento de forma simples, visual e interativa.

A interface foi pensada para transmitir uma identidade premium, elegante e feminina, utilizando tons escuros, rosa, dourado e efeitos inspirados em mármore. O fluxo de agendamento é dividido em etapas para facilitar a experiência do usuário.

✨ Funcionalidades
1. Seleção de serviço

O cliente pode escolher entre os seguintes serviços:

Design de Sobrancelha — R$ 15
Design com Henna — R$ 35
Extensão de Cílios — R$ 50
Extensão de Cílios + Design com Henna — R$ 85

Os serviços são apresentados em cards interativos e o botão de continuidade só é habilitado após uma seleção.

2. Escolha da designer

Atualmente existe uma profissional cadastrada:

Dominique Souza

Especialidades exibidas:

Sobrancelhas
Henna
Cílios




3. Seleção de data e horário

A página possui um calendário interativo que permite:

Navegar entre os meses;
Selecionar uma data;
Bloquear domingos e datas anteriores;
Visualizar os horários disponíveis;
Selecionar um horário para o atendimento.

Os horários são gerados entre 08:00 e 18:00, em intervalos de uma hora.

4. Cadastro do cliente

Antes da confirmação, o cliente informa:

Nome;
Número de WhatsApp.

O botão de confirmação é habilitado somente quando os dados mínimos são preenchidos. O telefone também recebe formatação automática no padrão brasileiro.

5. Resumo do agendamento

Antes da confirmação, o sistema apresenta um resumo contendo:

Serviço;
Designer;
Data;
Horário;
Valor total.




6. Tela de confirmação

Após confirmar, o usuário recebe uma tela de sucesso com os detalhes do agendamento.

Também existe a opção de:

Enviar os dados do agendamento pelo WhatsApp;
Fazer um novo agendamento.




7. Integração com WhatsApp

O botão "Enviar pelo WhatsApp" abre uma conversa com uma mensagem pré-preenchida contendo:

Nome do cliente;
Serviço;
Data;
Horário;
Valor;
Endereço do estabelecimento.




🎨 Identidade visual

A interface utiliza uma estética de luxo/premium, combinando:

Fundo escuro;
Rosa e rosa-mármore;
Dourado;
Gradientes;
Efeitos de vidro/transparência;
Sombras suaves;
Bordas arredondadas;
Elementos decorativos;
Microanimações.

A tipografia combina:

Cormorant Garamond para títulos e elementos de destaque;
Jost para textos, botões e informações da interface.

As fontes são carregadas diretamente do Google Fonts.

🛠️ Tecnologias utilizadas

O projeto é desenvolvido como uma aplicação frontend independente utilizando:

HTML5
CSS3
JavaScript Vanilla
Google Fonts
SVG
WhatsApp URL Scheme

Não há frameworks ou bibliotecas JavaScript externas necessárias para executar a página.

📁 Estrutura

O projeto atualmente está concentrado em um único arquivo:

└── index.html

Estilos CSS;
Tema visual;

Sistema de calendário;
Sistema de horários;

Integração com WhatsApp.
